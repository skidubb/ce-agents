# CE - AGENTS

Monorepo for Cardinal Element's agentic AI work — agent systems, orchestration protocols, evaluation frameworks, and automation workflows.

## Structure

```
├── CE - Agent Builder/     # C-Suite multi-agent system (ce-c-suite)
├── CE - Evals/             # Evaluation protocols & rubrics (CE-Evals)
├── CE - Multi-Agent        # Coordination protocols & research (coordination-lab)
│   Orchesration/
├── CE - Recursive Loops/   # Recursive agent loop patterns
├── n8n Workflows/          # n8n automation workflow definitions
├── Scripts/                # Shared utility scripts
└── Shared/                 # Cross-project shared resources
```

## Projects

### Agent Builder (`ce-c-suite`)
The C-Suite agent system — specialized AI agents for executive functions (CEO, CTO, CFO, etc.) with MCP server integrations.

### Evals (`CE-Evals`)
Evaluation framework for measuring agent quality — protocols, rubrics, and benchmarking tools.

### Multi-Agent Orchestration (`coordination-lab`)
Research and protocols for multi-agent coordination — communication patterns, delegation strategies, and team topologies.

### Recursive Loops
Patterns for recursive agent execution — self-improving loops, iterative refinement, and convergence strategies.

### n8n Workflows
Production automation workflows running on n8n — integrating agents into real business processes.
